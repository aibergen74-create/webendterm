About QuizNova

Interactive trivia platform created for Web Technologies-1 course.

QuizNova is a project developed by students of Astana IT University (group SE-2538). The platform includes interactive quizzes, a real-time leaderboard with CRUD functionality, live search and category filtering, a photo gallery with lightbox, and a client-side validated registration form.

Project Overview

Technologies Used:
  • HTML5 semantic layout
  • CSS3 (Flexbox, CSS Grid, media queries, variables)
  • Bootstrap 5.3 components and grid system
  • JavaScript ES6 & jQuery 3.7.1
Main Features:
  • Registration form validation with email regex and password strength meter
  • Live search and category filter for quizzes
  • Dynamic leaderboard table with CRUD and LocalStorage
  • Photo gallery with lightbox and jQuery fade transitions
